# Aster — Sustainable Wardrobe Assistant

A polished Streamlit starter prototype for the concept **Aster**, aligned with UN Sustainable Development Goal 12: Responsible Consumption and Production.

## Features
- Styled, responsive green/earth-tone interface
- Outfit suggestion from user-entered wardrobe items
- Occasion and weather-aware styling tips
- Sustainability prompts for rewearing, repairing, and rehoming clothes
