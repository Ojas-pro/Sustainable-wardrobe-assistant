# Aster — Sustainable Wardrobe Assistant

A polished Streamlit starter prototype for the concept **Aster**, aligned with UN Sustainable Development Goal 12: Responsible Consumption and Production.

## Features
- Styled, responsive green/earth-tone interface
- Outfit suggestion from user-entered wardrobe items
- Occasion and weather-aware styling tips
- Sustainability prompts for rewearing, repairing, and rehoming clothes

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the app:
   `streamlit run app.py`

## Current status
This version uses simple rules, not a trained AI model. It does not store user wardrobe data. Treat it as a starter prototype and describe it honestly in any project submission.

## Deploy for a shareable link
- Push these files to a public GitHub repository.
- On Streamlit Community Cloud, create a new app and select that repository and `app.py`.
- Deploy, then use the generated public app URL as the demo link.
